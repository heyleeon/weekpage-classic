# 名字和图标 · Name and icons

**中文**

本仓的代码按 MIT 授权（见 `LICENSE`），但下面这些不在授权范围内：

- 「WeekPage」这个名字；
- `backend/icons/` 里的应用图标和菜单栏图标。

你可以：fork、修改、自己构建来用；在介绍里说「基于 WeekPage Classic」。

发布你自己的改版（安装包、应用商店、网站下载）时，请换成你自己的名字和图标，也换掉 `identifier`（见 README「要发布自己的改版」），别让人以为那是官方的 WeekPage。

**English**

The code in this repository is MIT-licensed (see `LICENSE`). The license does not cover:

- the name "WeekPage";
- the app and menu bar icons in `backend/icons/`.

You may fork it, change it, build it for your own use, and describe your project as "based on WeekPage Classic".

If you publish your own build (an installer, an app store listing, a download page), use your own name, icons and `identifier`, so nobody mistakes it for the official WeekPage.
