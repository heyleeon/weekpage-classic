# Product

> 需求定稿没随本仓公开（见 `.agents/AGENTS.md`「权威文档」）。本文件只写一页摘要，冲突时以需求说明为准。

## 是什么

WeekPage（原名「任务台」/ task-desk，改名经过见 `decisions.md`）：一个用全局快捷键（macOS ⌃⌥Space / Windows Ctrl+Alt+Space）呼出、悬浮在所有窗口之上的 local-first desktop tool，把**日历、待办、收件箱、任务看板**放进同一个窗口，数据只在本机 SQLite。

## 为谁做 / 解决什么问题

给一个人同时推进很多件「要等别人、要分几步、有截止」的事的个人用户（作者本人日用）：随手记下 → 整理成待办 / 任务 → 在日历上看到什么时候该做、什么时候该去查，不用在日历 App、待办 App 和便签之间来回切。

## 当前核心功能

- 日历页：2 / 3 / 4 周网格（周数、第一行显示本周还是上周在设置里），滚轮 / 触控板 / 拖空白处按周上下滑动、离开今天时出现「回到今天」，日程 / 待办提醒 / 检查点 / 任务开始 / 截止五种条目，双击直接输入（时间自动识别），条目拖动排序或拖到别的日子，节假日与节气，今日速览胶囊。
- 任务页：左栏「待办」（重要程度排序、提醒、没做完的留着、今天完成）与收件箱（今天 / 定日期 / 变任务 / 删掉）；右栏三列瀑布流任务卡（状态、时间条、关键点：我来做 / 等别人 / 检查点，记一笔）；关键点、待办、收件箱左右滑完成 / 删除；没有「当前」关键点，带日期的关键点过了日期没勾就算逾期，在卡片、详情、日历、今日速览里标红，窗口收起时菜单栏图标出红点、每天 9:00 发一条通知。
- 任务详情、变成任务 / 新建任务、归档确认、归档页（分组、搜索、本月统计）。
- 系统集成：全局快捷键、失焦隐藏（可钉住）、托盘 / 菜单栏、开机自启、单实例（Spotlight / 开始菜单）、到点通知、白天 / 黑夜主题、中英双语界面（跟随系统或手动，托盘和通知也跟着）、所有操作可撤销。

- Windows：CI 保证能编译并打 NSIS 包，真机还没验。
- 上面的功能都已实现。只在浏览器预览和自动测试里验过、还没在真 App 上亲手验的事，以及已知缺口（比如关键点自动判型只认中文写法），都列在 `docs/roadmap.md`。

## 明确不做什么（1.0）

- 云同步、多端、账号、日程详情、自动更新、同步外部日历：本仓不做，归新版。
- 协作、分享、附件。
